# 任务栏性能监控

在 Windows 任务栏或屏幕任意位置显示两行三列的实时性能面板：

```text
CPU 12%     GPU 8%      内存 43%
磁盘 2%     ↑ 1.2M/s    ↓ 5.1K/s
```

支持卡片样式和无背景的透明样式（只显示文字）。

## 功能

- CPU、GPU、内存、磁盘活动率，以及上传、下载、上下行三个独立的网络指标；默认每 1 秒刷新。
  - 上传、下载各占一格，标签是箭头图标，样式与 CPU、GPU 一致。
  - 上下行把两个速率放进同一格上下两行，字号更小，适合窄面板。
- 两种位置模式：
  - **任务栏模式**：自动停在系统托盘左侧，跟随任务栏显示/隐藏；可以水平拖动到任务栏任意位置。
  - **屏幕浮窗模式**：可以拖到屏幕工作区任意位置，不会进入任务栏；可选择页面置顶或置底。
- **固定位置 / 解锁拖动**：默认固定，解锁后按住面板左键拖动，避免误触。
- **样式调整**：
  - 跟随系统颜色（自动匹配任务栏深浅色和系统强调色）。
  - 六套预置配色：深色、浅色、蓝夜、紫夜、森林、暖灰。
  - 背景色、文字色、标签色、边框色均可通过 Windows 颜色盘单独选择。
  - 背景图片：支持上传 PNG / JPG / BMP / GIF，可设置填充裁剪、拉伸、完整显示或平铺，并可调整遮罩强度。
  - 透明样式：不显示背景、边框、分隔线和圆点，只保留文字。
- **显示内容与名称**：CPU、GPU、内存、磁盘、上传、下载、上下行共 7 项可独立勾选（至少保留一项），每项的名称都能自定义，最长 10 个字符；名称留空或点“恢复默认名称”回到默认值，网络三项的默认名称显示为箭头图标。
- **顺序与排版**：
  - 7 项的顺序可以直接拖动调整（按住行尾的点阵握把上下拖），面板按“先上后下、先左后右”排列。
  - 面板最多两行，列数按勾选数量自动均衡（4 项 2 列、5–6 项 3 列、7 项 4 列）。
  - 列名固定在格子左侧，数值可选「居中」或「向右对齐」；两者的间距由列宽和列间距体现。
  - 列与列之间间距 0–32 px，调整时会加宽面板。
- **设置需要保存**：每个分类页底部都有各自的“保存”按钮，改动是草稿，点保存才生效；直接关闭会提示是否保存。
- 右键菜单和快捷键 `Ctrl+Alt+S` 都可以打开设置。
- 切换任务栏模式 / 屏幕浮窗模式时会自动解锁，方便马上拖动定位。
- 自动避开全屏游戏/演示；任务栏自动隐藏或为竖排时，任务栏模式会自动隐藏。

## 运行要求

- Windows 10 / 11 64 位。
- 系统自带的 .NET Framework 4.8（Windows 10 1903 及以上默认包含）。
- 无需管理员权限。

## 安装与运行

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本会把程序复制到 `%LOCALAPPDATA%\TaskbarMetrics` 并启动。也可以直接运行 `bin\TaskbarMetrics.exe`。

需要开机自动启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -AutoStart
```

也可以右键面板，选择“设置 → 开机自启动”。

## 使用

### 右键菜单

- **设置**
  - **刷新间隔**：1 秒 / 2 秒 / 5 秒。
  - **样式调整**：
    - 设置...
    - 跟随系统颜色
    - 透明样式（仅显示文字）
    - 数值对齐（居中 / 向右对齐）
    - 列与列之间间距
    - 背景 / 文字 / 标签 / 边框颜色...
    - 选择背景图片... / 清除背景图片
    - 背景图片填充方式 / 背景图片遮罩
  - **位置**：
    - 任务栏模式 / 屏幕浮窗模式
    - 页面置顶 / 页面置底
    - 固定位置
    - 解锁并拖动
    - 重置位置
  - **显示内容**：CPU、GPU、内存、磁盘、上传 ↑、下载 ↓、上下行 ↑↓ 七个勾选框
  - **开机自启动**
- **立即刷新**
- **退出**

### 设置窗口

窗口左侧是分类导航，右侧是对应设置；每个分类页底部都有本页的“保存”按钮，窗口底部只有“关闭”。

- **基础设置**：开机自启动、配置文件存放目录（可自定义）、恢复默认设置。
- **外观**：跟随系统颜色、透明样式、六套预置配色、背景/文字/标签/边框四个自定义颜色，以及背景图片（选择/清除、填充方式、遮罩强度）。
- **显示内容**：7 个指标的勾选框，中间输入框改这一项在面板上的名称（最长 10 个字符），右侧握把拖动调整显示顺序。
- **排版**：数值对齐（居中 / 向右对齐）、列与列之间间距。
- **位置**：任务栏模式 / 屏幕浮窗模式、置顶 / 置底、固定位置、解锁并拖动、重置位置。
- **关于**：当前运行数据、当前配置摘要、快捷键（本页没有保存按钮）。

窗口底部常驻一行灰色小字“仅供学习交流，严禁用于商业用途，请于 24 小时内删除”。

补充说明：

- 改动会立刻作用到面板上供预览，但只有点所在页的“保存”才写入配置文件；有未保存改动时直接关闭会询问“保存 / 不保存（还原）”。
- 各页的保存按钮提交的是同一份草稿，所以在任意一页点保存，也会一并提交你在其他页改过但没保存的内容。
- `Ctrl+Alt+S` 或右键“设置 → 样式调整 → 设置...”打开。
- 勾选“跟随系统颜色”后，颜色自动跟随 Windows 深/浅色任务栏。
- 点击任意颜色按钮会打开 Windows 颜色盘（可展开完整颜色矩阵并自定义颜色）。
- 屏幕浮窗模式可选择“置顶”或“置底”；位置会限制在屏幕工作区，不会放进任务栏。
- 切换位置模式会自动解锁；换好位置后可以用“固定位置”重新锁住。
- “重置位置”回到任务栏右侧默认位置。
- “恢复默认设置”会把配色、显示内容、名称、顺序、排版、配置目录恢复出厂值，面板位置保持不变。

### 配置文件

配置保存在一个可直接编辑的 `settings.ini` 里，默认在 `%LOCALAPPDATA%\TaskbarMetrics\`，可以在“基础设置 → 配置文件位置”里换到任意目录（比如放到网盘或 U 盘目录）。

- **读不到配置文件时，会在程序所在目录生成一份新的** `settings.ini`；程序目录不可写时再退到 `%LOCALAPPDATA%\TaskbarMetrics\`。
- 目录里会放三样东西：`settings.ini`（配置）、`TaskbarMetrics.log`（运行日志，含报错）、`background-*.jpg/png`（导入的背景图）。
- 日志也跟着配置目录走；如果那个目录写不进去，会自动退回默认目录写日志，不会把错误丢掉。
- 注册表里只保留一个指向该目录的指针（`HKCU\Software\TaskbarMetrics\DataDirectory`），其余旧键在首次读取配置后会被清理掉。
- 旧版本写在注册表里的配置会在第一次启动时自动迁移成 `settings.ini`。
- 换目录后需要点“保存”才切换；旧目录里的文件不会自动删除。

### 背景图片

右键“设置 → 样式调整 → 选择背景图片...”或样式设置里的“选择图片...”。支持 PNG、JPG、BMP、GIF；图片会复制到程序数据目录，原文件移动或删除不影响使用。

- 填充方式：填充裁剪、拉伸、完整显示、平铺。
- 遮罩：0–80%，用于保证图片背景上的文字可读性。
- 选择图片会自动关闭透明样式；重新勾选透明样式即可回到纯文字显示。

### 透明样式

在样式设置中勾选“透明样式”，面板只保留文字，任务栏背景完全透出。仍然可以右键或拖动。

### 拖动

1. 右键 → 设置 → 位置 → 解锁并拖动（或样式设置中的“解锁并拖动”）。
2. 按住面板左键拖动：
   - 任务栏模式只能左右移动，并跟随任务栏显示/隐藏。
   - 屏幕浮窗模式可以在屏幕工作区移动，但不会进入任务栏。
3. 右键 → 设置 → 位置 → 固定位置，锁定当前位置。

## 数据来源

- CPU：`GetSystemTimes` 两次采样差值。
- 内存：`GlobalMemoryStatusEx`。
- GPU：Windows 性能计数器 `GPU Engine` 的 3D 引擎利用率，按进程汇总后取最忙的 3D 引擎。
- 磁盘：`PhysicalDisk` 的 `% Idle Time`，活动率 = 100 - 空闲率；详细信息中包含读写速率。
- 网络：活动物理网卡的 IPv4 收发字节数差值；会排除 VPN、TAP、虚拟网卡，避免重复计算。
- GPU 没有 `GPU Engine` 计数器时显示 `--`，其他指标不受影响。

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

会结束程序、删除开机启动项和 `%LOCALAPPDATA%\TaskbarMetrics`。如果你把配置文件目录改到了别处，那个目录需要自己手动删除。

## 开发者

```powershell
.\build.ps1
```

使用系统自带的 .NET Framework 4.8 C# 编译器构建，无需 Visual Studio 或 .NET SDK。

调试面板排版时可以直接把面板渲染成 PNG，不必盯着任务栏看：

```powershell
.\bin\TaskbarMetrics.exe --preview preview-out.png 40
```

第二个参数是面板高度（默认 40），宽度按当前“显示内容”自动计算。

设置窗口也可以直接截图核对排版（参数是导航页序号，0 基础设置 / 1 外观 / 2 显示内容 / 3 排版 / 4 位置 / 5 关于）：

```powershell
.\bin\TaskbarMetrics.exe --shot settings.png 2
```
